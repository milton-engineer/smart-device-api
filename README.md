# Smart Device API

Java Spring Boot API designed for smart device control and monitoring workflows.

## Overview

Smart Device API is a lightweight backend service focused on simulating smart appliance management through REST endpoints.

The project demonstrates backend communication concepts commonly used in IoT environments and connected device ecosystems.

## Features

- Device status monitoring
- Temperature control simulation
- Power state management
- REST API endpoints
- JSON-based responses

## Technologies

- Java
- Spring Boot
- REST API
- JSON

## Goals

- Practice Java backend development
- Simulate IoT backend workflows
- Build lightweight device management APIs
- Explore smart device integration concepts

## Status

Initial development phase.
